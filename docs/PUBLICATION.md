本仓库从现有网页版工作目录整理为独立公开副本，不含个人 SSH 密钥、CLI 授权资料、软著申请材料、临时发布目录或 `node_modules`。原工作目录与现有 CloudBase 服务未被此整理替换。

## 授权与许可

维护者于 2026-10-24 确认素材权属并授权公开。自有代码和文字文档 MIT；自有地图、人物肖像设计与展示媒体保留版权；明确 CC0 的内容及第三方组件各自沿用原许可。

补存客户端 Colyseus、Schema、httpie、ws 的许可证，公开目录和 Docker 的 `public/` 内都有 SDK 许可副本。Fusion Pixel 使用固定历史提交的 OFL 1.1 文本；子集改用衍生名称 `Territory War Pixel`，字体轮廓与字符 advance 逐一校验保持不变，原始 TTF 未修改。

## 与原工作目录的区别

- `Room.js`、服务入口、ID 兼容桥、地图、兵种、图标、启动器与游戏数值不变。
- 客户端 HTML 与局内 CSS 仅同步字体别名；不是重画、改规则或重置手感。
- 服务端锁文件仅修补兼容范围内的 `body-parser 1.20.8 → 1.20.9`，处理发布时审计发现的压缩请求体拒绝服务问题。没有执行强制大版本升级。
- 添加根目录运行/测试入口、公开 README、玩法说明、维护约定、真实截图和明确许可边界。
- 精选原测试迁至 `tests/`，去除对私人临时工具的依赖；本机固定 Edge 路径的浏览器夹具不作为跨平台公开测试承诺。
- 不附 CloudBase 账号环境配置或私人隧道程序，使用者自行部署；GitHub Pages 只托管静态文件，不能代替本游戏的 Node.js/WebSocket 服务。

## 验证边界

原工作目录的 24 项 `tmp/` 回归及 29 个 JS 文件加客户端内联脚本语法检查已通过。公开副本从独立 npm 安装验证：默认 16 项测试、8 个联机脚本、7 个真实浏览器开局场景全部通过；浏览器覆盖五图单人、已有 AI 和双真人开局。补存与字体重命名后的 HTML/JS 语法检查通过，生产依赖审计为 0 漏洞。字体对全部实际字符的轮廓与 advance 比较一致；Unicode 非字符不作为可显示字形断言。

这些验证不是低端手机长局实测，也不是小游戏平台审核。发布到 GitHub 不会自动把本轮依赖修补部署到原云服务。
